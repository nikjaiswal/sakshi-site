# DESIGN.md

The design system behind `site/assets/style.css`. Adapted from the DOJO
site by MIT Critical Data (https://github.com/criticaldata/dojo, MIT
License). SAKSHI-specific additions follow the "SAKSHI additions" marker in
the stylesheet.

## Tokens

Colors (`:root`):

| Token | Value | Use |
| --- | --- | --- |
| `--color-ivory` | `#f5f1eb` | Page background, hero, contributors section |
| `--color-paper` | `#fffdf9` | Cards, inner pages, text on dark surfaces |
| `--color-ink` | `#25221f` | Body text, Protocol section background |
| `--color-muted` | `#6e6861` | Secondary text (4.9:1 on ivory) |
| `--color-terracotta` | `#8f3f30` | Accent: eyebrows, primary buttons, pins, focus ring |
| `--color-sage` | `#2f634e` | Contact section background, inner-page links, hub mark |
| `--color-line` | `#d8d0c7` | Rules, borders, map dots |
| `--color-soft-gray` | `#e6e0d8` | Code background, media placeholders |
| `--color-mit-red` | `#a31f34` | Only inside the MIT Critical Data logo |

On the dark Protocol section, accent labels use `#d58673` (5.6:1 on ink)
and the focus ring uses `#f0c4b8`. Light theme only; `color-scheme: light`.

Type:

- Display: `Georgia, 'Times New Roman', serif` for h1 to h3, weight 400,
  tight letter-spacing (`-0.055em` on h1, `-0.045em` on h2).
- Body: `Inter` from Google Fonts, falling back to the system sans stack.
- Devanagari (the hero eyebrow): system Devanagari stack.
- Eyebrows and labels: 0.76 to 0.82rem, weight 700, uppercase, letter-spacing
  0.12 to 0.16em.
- Reading measure: inner-page prose capped at 66ch.

Spacing and shape:

- Container: `min(1120px, calc(100% - 5rem))`; narrower at 960px and 760px.
- Sections: `clamp(6rem, 11vw, 10rem)` vertical padding; inner pages less.
- Radius: 4px on cards, 999px on buttons and chips, 50% on marks.
- Shadow: `--shadow-soft` only on the mobile menu.

## Components

- **Header**: sticky, brand (eye mark in a ring + SAKSHI) and the MIT
  Critical Data logo separated by a rule; nav collapses to a menu under 760px.
- **Status line**: one sentence under the header on inner pages, and in the
  hero on the home page. Required on every page.
- **Hero**: eyebrow, serif h1, lede, status, button row, and the witness-eye
  animation (SVG + CSS + small JS; still image for reduced motion).
- **Section heading**: numbered eyebrow ("02 / The Protocol"), h2, one
  paragraph. The number encodes real order on the home page only.
- **Principles list**, **plane cards** (four-up variant), **flow steps**,
  **evidence strip**, **paper cards** and **paper list**: DOJO components,
  used for the principles, domains, profile lifecycle, record, and
  publications.
- **Contributors map**: dot-matrix world (one stroked path), terracotta
  pins with uppercase labels, sage hub, country chips. Generated by
  `tools/make-world-map.py`.
- **Contact card** on sage; primary and quiet buttons.
- **Inner page**: `.section--page` with a section heading and `.page-prose`
  (headings, lists, definition lists, tables in `.table-wrap`, boxes,
  composite banner, numbered phases, badges, citation aside).
- **Template controls**: text inputs, selects and textareas on paper with a
  line border; toolbar with pill buttons.

## Rules

- Every page ends with a citation aside pointing at the paper.
- Links in prose are sage; the accent is reserved for eyebrows, numbers,
  primary actions and the map pins.
- Motion is decorative only and switches off under `prefers-reduced-motion`.
- Standalone links have at least 24px of target height.
- No inline styles; html-validate runs in CI with the recommended preset.
